# 学习记录与断点续学

用户希望跨会话继续时才创建记录文件，路径由用户指定，否则用当前工作目录下的 `algo-learning-log.md`。一题一节，追加不覆盖。

## 模板

```markdown
## 2026-09-18 统计重复请求

- 真实问题：从访问日志里找出出现次数大于 1 的 URL
- 朴素解：双层循环计数，O(n²)
- 瓶颈：10 万条时 40 秒，内层每次都重新扫全表
- 优化：字典计数一次遍历，O(n)，0.05 秒
- 题型：哈希表查存在（两数之和、存在重复元素）
- 语法点：`dict.get(k, 0)`、`items()` 解包、`sorted(key=...)`
- 卡点：对 `d[k] += 1` 在键不存在时会 KeyError 反复踩
- 阶段进度：1-5 过关，6 面试表达未做，7 独立复现未做
- 下次开场：先让用户不看代码重写字典计数版
```

## 续学做法

新会话开始时先读记录，然后：

- 从「阶段进度」标注的第一个未过关阶段继续，不重讲已过关的部分。
- 先用「下次开场」里那道回顾题热身；用户没写出来，说明上次的过关判断偏乐观，退回上一阶段重做一遍逐句循环。
- 「卡点」里出现两次以上的语法点，在下一题里刻意再让用户用一次。
